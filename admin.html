কোড ডিস্ট্রিবিউশন এবং গিটহাব ইন্টিগ্রেশন

আপনি ড্যাশবোর্ডে যে পরিবর্তনগুলো করেছেন তা এই ব্রাউজারে লোকাল স্টোরেজে সংরক্ষণ করা হয়েছে। আপনার ওয়েবসাইটকে গিটহাব এবং ভার্সেলে আপডেট করতে হলে নিচের ফাইলটি ডাউনলোড করে আপনার লোকাল রিপোজিটরিতে `app.js` এর জায়গায় পরিবর্তন করে পুশ করুন।

কিভাবে কোড আপডেট করবেন (GitHub CLI ও Vercel):

  1. ফাইল প্রতিস্থাপন: আপনার ড্যাশবোর্ডের ডিরেক্টরিতে ডাউনলোড করা app.js ফাইলটি দিয়ে আগের ফাইলটি প্রতিস্থাপন করুন।
  2. টার্মিনালে কমান্ড রান করুন: 
    git add app.js
git commit -m "Update writings from admin panel"
git push
  3. স্বয়ংক্রিয় ডিপ্লয়মেন্ট: কোড পুশ হওয়ার পর Vercel স্বয়ংক্রিয়ভাবে নতুন চেঞ্জগুলো নিয়ে লাইভ ওয়েবসাইট আপডেট করে দেবে।
