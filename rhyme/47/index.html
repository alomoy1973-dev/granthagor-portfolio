থিদো নেই জীংকানি,

১৩/০৫/২০১৫ — 2 মিনিট পাঠ

থিদো নেই জীংকানি,

দিয়ে নেই বুক্ বানি।

দুঘে দুঘে পরাজে ধুরি ;

দিক্কোনী কিয়োজনে??

কেনে পড়ে...ভাত্ পোইয়ত্ মুরগুজি!!!

ঝাড়ে জঙলে ঘুরি ঘুরি ;

বাঘ্,

ভালুক্কোই লাড়ে গুরি!

অভাবত্ আলু কুড়ি,

খেই ইচ্চন্ বুড়োবুড়ি।।

ন' ছাড়ন্ মান্ ইজ্জদ্,

বিজি ন' হান্ দেজ্-জাত্

ধুরি রাগেয়ন্ সংস্কৃতি।।।

ইক্কে তর নুদিগীরি ;

চিজিক্ চাজাক্ হিরিমিরি।

চোখ্ তনতনায় পাজনান্ ;

কধা বাট্টার ঘাজনান্।

এজং ন' এজং র'বো....ননিয়ে তুই মা-বাবর।

এক্কা কধায় রাগ্ জ্বলচ্ ;

এতাত্যে,,,

তর দিল্ ডাঙঁর,

জাত্ ফেলে বেজাত্ লচ্।।।

ছড়া সংগ্রহে ফিরে যান
