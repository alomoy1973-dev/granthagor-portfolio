ওলি (ঘুমপাড়ানি)

০৫/০৯/২০১৬ — 2 মিনিট পাঠ

চিজি,

চিজিকরে ঘুম্ নেয়ে নোয়াই ঘরান্ কাজেস্,

... ভাতিপেলবু ওদোরেস্,

...তোন্ একপদ্ রানিস্,

আমি জুমোতুন্ এলেগোই গরম্ গরম্ তিদেশাক্ রাহিন হেবংগি।

এদ্দুরাত্ হোইহাই মা-বাবে কামত্ যান্। মা-বাবর ডাঙরেবো অলে বানাহ্ দুখ্!

চিজিকরে এবার ঘুম্ নেজানা! দবছহবে ঘুম্ ন' যায়! ঘুম্ ন' নেজেলে কাম্ গুরি ন' পায়। ঢুলানত্ পেড়ল'।

... বেবে মেরে একান্ হেতয়া হোই দে।

... হেতয়া হোই দিলে ঘুম্ যেবেনি?

... য়েম্,

... শুনিথাক্ বেজাস্...

ওলি

এ...তে...এ...এল' এক্ রা...জা...!

রাজার এলাক্ তিন্নো পুও।

তিন্নো পুওই রেজ্য চান্।

মাতর,

কিযয় প্রজারে কোচ্ ন' পান!

...বেজাস্! হুঁ পড়া চিকো...

... হুঁ!

সেনতয়ে রাজাহতাহ্ ভাবীনে।

সনার চিকো তরে হোচ্ পেইনে।

তরে দিল' রাজ্য ভাগ্।

সনার চিজি চুকি থাক্।

...বেজাস্!

... হুঁ!

রাজার আগন্ ঘেয়দ-ঘড়া।

সোনা-রুবো দুল্ ভরা!

দুধালী গরক্ ন' হরন্।

হে পারিবে চিকো, পেঠ্ ভরন্!

... বেজাস্!

... হুঁ!

যুনি রাজায় গেরে ভাগে ভাগ্।

রাজায় তিন্নো পুওয় ন' পেবাক্।

চেই থাক্, চিকো তুই চেই থাক্।

তরে হামাঙায় দিব' ডাঙর ভাগ্।

সনার চিজি চুকি থাক্।

... বেজাস্!

... হুঁ!

রাজার ঘরত্ রাজার ঝি।

পরী মিলে সান্ গুরি।

আমিজে বেরেই থান্ লেগে সমারী।

রাজার ঝিবো সেষা দোল্!

চিকো তুই দেলে, অবে ওল্!

... বেজাস্!

... হুঁ!

কানিলে মুকো ঝড়ন্!

আঝিলে মানিক্ পড়ন্!

আধিলে হুজোত্ ফুল্ ফুদন্!

রাজার ঝিবো এব' পালিকত্ গুরি।

চিজিরে নেজেব' করত্ গুরি।

রাজায় তা ঝিবো বো দিব'।

সনার চিজি এবার ঘুম্ যেব'।

... ঘুম্ এজের চিকো?

... ইইই... (ঘুম যার...)

—০৫/০৯/২০১৬ ইংরিজি।
