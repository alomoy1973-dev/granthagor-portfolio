হোম কবিতা ছড়া গল্প গান পরিচিতি
ছড়া

চুলেমূলে লাচ্যা হুল্ ;

০৮/০৭/২০১৫ — 3 মিনিট পাঠ

চুলেমূলে লাচ্যা হুল্ ;

পোড়া ঘুত্যা কিয়া রং।

মুজুঙো দাত্ ইক্কোও নেই ;

আর' নেইদি চোগো বং।

আধ্ ঠেঙাঁনি লিত্তিঙ্ লিত্তিঙ্ ;

উত্তান্ চেলে ধোলিয়া।

যেন্,

বুদু ছিনা শুগুরিগুলো ;

হিয়োই নেই মোলিয়া।

বুনোহাদায় পাঙগা ;

কোনো কাম্ বাগি নেই।

দিয়েল্যা সুধোনাল্ পাদাস্যা গুরি ন' পারে ;

পিনে পুরিবো কিনিনেই।

মরিচ্ দিলে অলোদ্ ন' দে ;

সিদোল্ দিলে নুন্।

কোই ন' ফুরোয় সেদক্ আগে ;

মর লাঙোনীর গুন্।

মনান্ তার ভারী দোল্ ;

চোখ্ পিজিনে রিনি চায়।

দিন্নো এলে য়াজার পুরোয় ;

পর' হুত্তুরি মাধি পায়।

মাঞোঁ নাঙেঁ এলাফেলা ;

মুই তা নাঙেঁ রাধামন্।

তারে লোম্বোই হামাক্কায় ;

জীংকানি মনলে পাদারি অং।।।

ছড়া সংগ্রহে ফিরে যান
