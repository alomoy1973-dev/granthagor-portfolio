ভুদেমারে ভুদেমা ;

২৯/০৬/২০১৫ — 1 মিনিট পাঠ

ভুদেমারে ভুদেমা ;

কোইদেনা তুই কোইদেনা।

নাদেং তোগে চুপ্ ন' পাং ;

মামা ডাগের ওয়াং ওয়াং।

বিনি পিধে,

শান্নি পিধে ;

জেদেনা খৈয়ত্ দলা মিধে।

মুই ন' খেনে তরে দিম্ ;

সে বদলে নাদেংয়ো নিম্।।।

ছড়া সংগ্রহে ফিরে যান
