ছড়া

পিজুম্ বাজত্ তেনতেঙুরি ;

২২/০৭/২০১৫ — 2 মিনিট পাঠ

পিজুম্ বাজত্ তেনতেঙুরি ;

হুত্তুন্ উড়ি এলে।

বাচ্চে থাক্ লেজত্ ধরঙ্ ;

শান্নি পিধে খেলে।

বাবা মলের শান্নি পিধে ;

মামাহ্ দেল্লোই ঘে পিলা।

জুরগো উরে আর' আগন্ ;

খাজুরো মিধের খৈ মলা।

উত্তোমাজাত্ নুন্ চুমো ;

লুডুঙ্ ভরন্ মাছ্।

ধুমো উজু নুনোমাছ্ ;

আর' কি কি চাস্?

উড়ি বেড়াস্ ইন্দি উন্দি ;

দুনিয়ে খবর পাহছ্।

দেঘে দিবে?

কুদু আগন্ ;

পিত্তুঙগুলো গাছ্।

ছড়া সংগ্রহে ফিরে যান
