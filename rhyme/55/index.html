১৬/০৬/২০১৫ — 3 মিনিট পাঠ

ধুধুক্ বে' বে' তেত্রেতুক্ ;

টঙঁ ঘরত্ ভজান্ সুখ্।

পিবির পিবির বুইয়ার বায় ;

কাষ্ট কিয়া জুরে যায়।

শিঙেঁ বানে পার্বূয়া বাজ্ ;

রেত্ নীঝি অলে শুনি থাক্।

লাঙ্যাঁ-লাঙোঁনী মন্ কধা ;

কোই ন' পেলে মন্ কাদা।

জুমো তুগুনোত্ ঝুবুর গাজ্ ;

টঙঁ ঘরত্ পার্বূয়া বাজ্।

পার্বূয়া বেততোই ভিরি বান্ ;

তদেগর জু পাগানা ধান্।

দেবায় গল্ল' ঝড় মূঘী ;

চিগোন্ দাধা যিয়ে জুম্ চুগি।

গায় গায় আগে টঙঁ ঘরত্ ;

চিত্ ন' ভিজের পরানত্।।।

শিঙেঁ = ১০/১২ আধ্ লাম্বা বাজর বাদ্যযন্ত্র।

যার র' ২/৩ মেল্ সং শুনা যায়।

২*পার্বূয়া = একজাত্ বাজর নাঙ্।

বুনোহাদাত্ বেশ্ বেবআর অন্।
