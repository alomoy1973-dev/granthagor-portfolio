১৭/০৬/২০১৫ — 4 মিনিট পাঠ

পাদি,

বালোচ্ কবালত্ নঅ জুধে ;

ভাঙাঁ তলোইয়র বেত্ পিদিত্ ফুদে।

কাদে ইচ্ছেই দিম্মাদান্ রুধে রুধে ;

নহে হুম্বিক্,

সয়ে দুখ্,

ন' ভদভদে।

তুয়ো শিঘেলুঙ্ দ্বি-এক্ মাত্রা আওজে ;

কিজেনী কন্ কূ হেনর,

কন্ ধারাজে।

কন্ বুড়ো হুদু মত্তন্,

যার গা'ত ন' বাজে ;

মা,

বাবর নাঙ্ নেই,

সে পুও বিদেজে।

বজর' মাধাত্ একদিন্ তে সময় ন' পায় ;

এব' ভিলি আওজে মা,

বাব' কায়।

ডেনে নেই,

বাঞেঁ নেই,

বুজ্যা বুড়ি গায় গায় ;

মোঘো কধায় মাসমূলা সংসার বেড়ায়।

তা মা আগেহ্ বিচ্চোনত্ ঝুরিঝুরি ;

গাঙ্ হুলে কুম্-কুত্তি,

কমলে যায় জুরোগুরি।

বানাহ্ ভাবঙ্,

কেনে যেম্ সংসার ছাড়ি ;

মামাহ্,

বাবাহ্,

ন' ডাগন্।

ডাগন্ ইক্কে বুজ্যা-বুড়ি!!!

নাদিনে ন' পারন্ বেলে,

জাদর ভাচ্ ;

আদামত্ এলে ভিলে পেবাক্ লাজ্।

মজা,

পুগি,

পুক্,

জুক্,

আদাম' কাজর ;

কেনে কেনে সয়েবাক্,

দুখ্ অ'সায়র।

অ'লে পুড়িবাক্ পিড়া,

ইধু ডাক্তরও নেই ;

ন' এজন্ আদামত্,

বেক্ কিজু ভাবীনেই।
