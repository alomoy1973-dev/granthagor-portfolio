কবিতা

মা

০১/০৮/২০১৫ — 3 মিনিট পাঠ

মা তর হোচপানা ;

গরঙর তবনা।

হদক ভাবনা ভাবীলুঙ ;

সাল্লেঙান ন' পেলুঙ,

হাল্লোই দিম্ তুলোনা।

সেনে মর এজ' ন' অয় ;

মা,

তরে নিনে হোবিদে লেঘানা।

যুনি এক্কা ছেরান পাং ;

হাদিমাস্যা পুনংচান্,

ত' ধাগত থোই চাং।

পুনংচানান সাদেচ্যা লাগে,

যেদক চেদুঙ ছাদ্ ফিরেপাগে।

ঈধোত উদিলে মা ত' মুয়ান।

অ'সায়র অঝার পিত্থীমি ;

যা চেলুঙ্ রিনিভিনি।

ভারীদ' ;

হম্বা পারাহ্!

সিয়ত ন' আবুজে বিস্বেস্।

সিয়ত ন' বানে বুক।

সিয়ত ন' জুরোয় পরান।

ভাবীলে বেক্কুন সাদাঙা,

মা,

ত' হরবো ছাড়া।

যক্ক-রক্ক,

কুবের ধন ;

অদ' নয় এক্কুই সং,

বানাহ্ তর এক ফুদো দুধো সান্।

পিত্থীমির বেক হুজীর আঝি ;

এগত্তরে আজিপুঝি,

সিয়েনিতও তোগে ন' পাং,

মা তর মিধে আঝিয়ান।

পিত্থীমির বেক মেইয়াঁআনি ;

যুনিও হুরে আনি।

তলেলুঙ মা তর হোচপানা।

মা,

তুই বানাহ্ তল্লোই তুলোনা।

সেনে মর ন' অল'......মা,

তরে নিনে হোবিদে লেঘানা।।।

কবিতা সংগ্রহে ফিরে যান
