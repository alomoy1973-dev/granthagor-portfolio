বাচ্ছে থাক্

১৫/০৬/২০১৫ — 4 মিনিট পাঠ

রানজুনি রঙেঁ পঙঁ সাজে ;

মনর ডিঙাঁত দাড়ঁ বজে।

বড় ব' হাবাত্ পাল্ উড়ে ;

এগা মনে এগা ধুরে।

ছাড়ি দিলুঙ্ এই ডিঙাঁ,

জুম্মবী ত' উধিজে।।।

বন্দর ছাড়ি বন্দরে ;

কন্দরে কন্দরে।

ভঙীম্ সে ভঙীম্ ;

ন' ভাঙীম্ ন' লুঙীম্।

অংনাহ্ পাগল্ সান্,

৪*ভিলেম্ গুরিম্ ঘরে ঘরে।।।

হুজর মাজারা ধুরি ;

ঝাড়-জঙল্ ফুরি।

দনাদুনি,

বিলপাদার ;

ঘোনাঘুনির শেজ্ মাধার।

পাদা উল্লে উল্লে,

ঝুপ্ ঝাড় ঊরী ঊরী।।।

যেন্ তগেয়ে নোয়ারামে ;

ভিরুং ভিরুং পরানে!

তগেম্ তরে দেজ্-বিদেজ্ ;

ওকনাহ্ জীংকানি শেজ্!

দেবাকালা মূয়োয় মূয়োয়,

বাঘ্ পারা হরানে !!!

আগে এলে পুন্নিমা চান্ ;

ইরুক্ গহর দুঘোর গান্!

কন্ ভোজোর হত্তালে ;

হাঙঁর মাজর বদলে।

তুলি নিলেক্ চিল্ শোভোনে,

দুলুহুমোরী সান্!!!

কুধু আগছ্ কিঙোরি ;

অঘুর ঝাড়ত্ নিউরি।

বাচ্ছে থেচ্,

এজঙর হঝা ;

পুনোত্ বানি ভাতমজা।

রেজ্যত্ ফিরি জাদর চোখ্,

দিবং তল্লোই পহর গুরি।।।
