ষোলো *বেইয়া ফুলর হাদি বুনি ;

সজমজ্ গুরি বুগোত্ বানী।

আঝং আঝং মূ নুদিবানী।

হেলাঙ্ হিলিঙ্ এ মুড়োমুড়িত্ ;

যেন্ শাওন্ ভাধ' মাস্যা,

জ্বলের বেবে বুগোত্ রানজুনি!!!

বৈজাখ্যা চোখ্ চোখ্ দেবাকালা ;

লাম্বা তার যেন্ চুলানি,

দ্বি তিন্ বের দিনেইও আলাঝালা।

চুলসুধো তাকঠিগিনীত্ ;

বুইয়ারে উড়ের কানজাবা চুল্ ;

চেমনি ন' চেম্??

চেবারও মনে হয়,

দ্বি চোখ্ মর ঝালাপালা!!!

কালা পিনোন্ রাঙাঁ হাদি ;

নয় অজল্ নয়ও বাদি।

রাঙাঁচাঙাঁ পরানবী মর,

ফিরেপাগে রিনি চেলুঙ্,

চোঘো লেজে মুরে মুরে।।।

স্বর্গর বেক্ সুখ্ এব' ;

নরগর বেক্ দুখকোনি ধেব',

আঝি আঝি পরানবী.......যুনি বোই থাচ্ মর কায়কুরে!!!

সে গমান্ গম্ ন' পাহন্।

নয় নয় নয়.............!!!

জাগি উধে রেচ্য পিড়ে ;
