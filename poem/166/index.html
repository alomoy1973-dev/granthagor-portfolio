তারিখ অজানা — 1 মিনিট পাঠ

ঈধঘর তিদি উধে ;

বিঝু রঙেঁ মনান্ রাঙেঁলে।

ফিরিযাং চিগোন্ কালত্ ;

রোদ্-ঝড় মোয়েঁ....

তিদির তিদির বেড়ানা!!

ছদানর একদলা পুক্ ;

নিত্য মাধাত্!!

চোগোত্ ভাজন্ সে দিনুন্ ;

হর' হর' মিধে মিধে।।

ছিলোনো ধোর শীলোত্ ঘুজী ;

ধারপাত্তি তুলি।

ঝুড়ি পুজ্যা করাহ্ আম্ ;

থাহর নেই কবাল' ঘাম্ ;

ছুলি খেয়েই কাজর গুলি।।

ফুলবিঝু এলে ;

ঘুম্ নেই রেত্য অলে।

কদ' কধা সয়সাগর ;

থাদারত্ রেত্য পহর!

কন্যাঁ আগে তুলিব' ফুল্ ;

ফুল্ ফুল্ চুলচুল্.....

বিচ্চোনত্ পুরি থানা ;

ঘুম্ ন' অয় গমেদালে!!!
