মর স্ববনানি (মোর স্বপ্নেরা

১৬/০৭/২০১৫ — 3 মিনিট পাঠ

মর আঝার (আশা) স্ববনানি উড়ি যায় ;

মাদি পিত্থীমি ঠান্ ন' পায়।

পাগত্ পলে বড় ব' হাবাত্ ;

ধুব্ ধুব্ মেঘ' ছাবাত্।

সেমেততুলো গঙেঁ,

বানাহ্ ভঙেঁ।

মনানত্ নানান্ রঙে ;

রং ফুদি যায়।

স্ববনানি উড়ি যায়,

ধুরি চাং,

ধুরি ন' পায়।।

কন্ দেজর কন্ রাজার ঝি ;

কেনে কিঙোরি গেল' য়াঁজি (হারিয়ে)।

ব্যঙ্গমা-ব্যঙ্গমীর জোব্ নেই ;

ইন্দি রাজ্যপাট ছারিনে,

অঘুর তারুমোত্ রাজ্-রাণী!

ছলঙান্ ছাড়ি,

সপ্পানত্ ঘুরি ;

সিদুও থায় মর স্ববনানি।।

মর স্ববনানিত্ নেইআঝা (আশা) ;

গোড়া আগে নেই আগা।

আগে পিত্থীমিত্।

কন্ জাগা,

কন্ বন্দরত্ আগে গুজি!

নাহি দোলবীর নুদি আঝিত্!

উদো নেই,

উদো নেই.... কুদু যিয়ে কিজেনী!

মর দোল্ স্ববনানি।।।

কবিতা সংগ্রহে ফিরে যান
