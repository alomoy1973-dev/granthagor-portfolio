ভাবর নি?

২৯/০৭/২০১৫ — 3 মিনিট পাঠ

পাগে ওক বা বে'পাগে ;

রদবল যেক্কন আগে।

গায় গায় ওক বা সমাজ্যা লগে ;

হাদর দ' দিন ঈলে ঈলে বিলে বিলে।

হি গুরিলে বসহালে ;

হানিলে না আঝিলে।

বিদিযিয়া দিনুন হেনে গঙেলে ;

যেক্কে হজকহাজাক গুরিবেক আধুঘিলে,

গুনিচেচ্চোই,

হুলোন্নি আঙুঁলে।

লাজ-ডর নেই হাররে ;

বাঘে ন' পেবাক লড়েলে।

সেনে তর পিজেদি ঘিলা!

বিঞ্যাঁ হেলে বিল্লা চেলা।

বিল্লা হেলে বিঞ্যাঁ চেলা।

ত' ভাজে বসহাল্যা সুখ ;

মানে জিংহানিত আলাঝালা।

যেক্কে এবাক গাঙহুলে হুম-হুত্তি ;

তালাস লবে জ্ঞেদি গুত্তি।

হিচ্চু ন' থেব'চ্যা উত্তি পুত্তি।

হা হবর হন্যাঁ লর ;

ইন্দি তুই দিন গুনর।

ধনে শুন্যঁ,

বলে য়িন ;

ঘনাঘুঞ্যাঁ অবাক দিন।

হি গুরিবে সেক্কেনে???

যুনি মুরিযাচ একবুক চিদেলোই ;

স্বয়ং বর্মা গুজি ললেও.....সেক্কে তর বুক্কো পুড়ি যেদ' নয়!!!

কবিতা সংগ্রহে ফিরে যান
