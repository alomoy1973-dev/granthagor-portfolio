ভেজে দেনা #( স্পাইগিরি

০১/০৬/২০১৫ — 3 মিনিট পাঠ

কন্ যুগোত্ কন্ দাগীয়ে ;

কা ঝি বো আনি,

পেল্ কি ন' পেল' কিজেনী।

সে দুগোআল' কধানি ;

চিগোন্ কানিলোই গিরেবানি,

জু তোগে আগে কেনাবানি।

আওজো আঝা মাদি ওল্,

দেঘা যোক্.....চাং সালে এবারত্ ;

সাত্ ঘাধ' পানি.....কন্ বাঘ্ কন্ ঝাড়ত্!!!

দিন্ এন্ জু অইয়ে ;

ভাক্ অলঙ্ ভেইয়ে ভেইয়ে।

যারা হের আদাম্ বানি ;

উজোল্ গর' কেনাহেনি!

এজু পা জু নেই ;

মুরে মুরে ভেজে দিই!

উদিবজস্যা পিড়ানি ;

জাগে তুলি এক্ সাজ্ হাবে....কন' ঈল্ মরেনি!!!

বাড়ে বাড়ে দোল্ দোল্ ;

মুরে মুরে ওল্ ঝোল্!

এ কেনা,

ও কেনা ;

কেনে কেনে উজোল্ গরানা!!!

দারবুয়া হঝা,

পাদা কাবা ;

বেপাগেও যুনি হচ্ কূজবা!!

সালে,

পুরঘাত্ ঠিক্ অয়ে ;

লগে লগে ভরমেল' শনিয়ে!!!

আধ্-ঠেঙ্ বানি নেজানা ;

বানাহ্ ক্ষন্ বাচ্চে থানা।

ইরুক্......গদা জুম্মো বাপ্-ভেই,

মা-বোন ;

দেঘির কালা ধুমো বনাবনাহ্!!!

কবিতা সংগ্রহে ফিরে যান
