১৩/০৭/২০১৫ — 7 মিনিট পাঠ

তুলি পারংনি ঈধোত্ ;

বারিজের এ দিনোত্।

"ঝড়"র কোবিদ্যার কধানি।

আওজে কলম্ লোই ;

এগামনে চানাত্ বোই।

রোলুং ঝড়পুদো গুনিগুনি।

ন' পারিলুঙ্ কলম্ পাগে ;

ঝড়ান্ গেলগোই থিগে।

রোদে,

সেরাংমেরাং পিত্থীমি।

কবিতা ন' ওল্ থুম্ ;

ন' ওল্ দ্বি চোগোর্ ঘুম্।

সার ওল্ ঝুড়ুনী।।।

নুলি ফেরে রোদ্ মূখ্যে ;

ন' বুল্যা কলম্ জুক্কে জুক্কে।

দাধে দাত্ চাবাঙর ;

ঝিমিঁয়া ওই ভাবঙর।

সাজগুঙিঁ রেত্ ওল্ ;

চোখ্কুন অ'লাক্ ওলোঝোল্।

নেই আর দিনো পহর ;

খেমানেই ভাবঙর চে ভাবঙর।

ভাবনার থুম্ নেই ;

কোবিদ্যার দেঘা নেই।

ইয়ান্ হি মর কাম্ ;

ফেলেলুঙ্ চুধো ঘাম্।

ঝলক্ ফলক্ ন' যার দেঘা ;

যা ওল্ ন' বুল্যা লেঘা।

ন' পারিলুঙ্ পিঙ্গুল্ গুরি ;

কুজ্ বাদে দিলুঙ্ ইরি।

অলে ওক্,

ন'লে নেই....যা কবিতা যা উড়ি।।।

*কুজ্ = আরানা,

থুম্ ন' অইয়ে কাম্।

১০/০৭/২০১৫

১৩৭)কবিতা

[ সমার (বন্ধু) মরে কোচ্ পেচ্ ]

মুজুঙোত্ চোখ্ পুজিলেও ;

আবিজ্জনে কোচ্ পেচ্।

যুনি থায় কোচপানা ;

চিতদীঘোল্ ভাবনা,

মুজুঙোত্ হ্যান্ডসেক্ ন' গুরি,

লাদি ইক্কো দিই যেচ্।।।

তর কোচপানা থোক্ মনে মনে ;

ন' জানোদোক্ কিয়জনে।

থান্ থোক্ পরানত্ ;

বানাহ্ জানোক্ গোজেনে।

জীংকানি আধিবার পধত্ ;

সুঘোর সমার ও ন' পেলে,

আবিলেশ্ ন' হেচ্।

দুঘোর দিনুনোত্ যুনি ;

সাঙেঁত্ সমার ন' পারচ্ বুদি,

কবাল্ বিনেবিনে পোত্তেচ্।।।

পেবার আঝায় ন' ওক্ কোচ্ পা'পি ;

কি পেলুঙ্ মনানত্ ন' ভাবী।

দিবার নাঙেঁ তর-মর মনানে ;

আমিজে গরোক্ আধ্ বাভাহবাভি।।।

মর মরা'ত্ ফুলর গোজালোই ;

আগমুলিম্ তুই ন' এচ্।

মাঞোঁরে দেঘে দেঘে,

বুগোত্ কালা কাবর ন' লাগেচ্।

শোক্ মিশিলত্ বেগ'পিজি,

আধি যেচ্ আঝি আঝি।।।

কোচপানা দেঘেবার নয় ;

বানাহ্ তবনা,

বানাহ্ তবনা,

ইয়ান্ ঈধোত্ রাগেচ্।

যুনি মরে কোচ্ পে থাচ্.......কোচপানার কেনাহ্ মারিবের চাস্।

নানু আরেইয়া মর নুও তম্বায়ুন্,

দ্বিবা চোখ্ তুলি ফিরি চেস্।

সেন্ গুরি তুই মে কোচ্ পেচ্।।।

থান্ = জাগা,

স্থান্।

**তম্বা = প্রজন্ম,

তম্বায়ুন্ = প্রজন্মগুলো,

নুও তম্বায়ুন্ = নতুন প্রজন্মগুলো।

কবিতা সংগ্রহে ফিরে যান
