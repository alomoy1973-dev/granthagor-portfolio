মিধে আঝি

১৩/০৬/২০১৫ — 3 মিনিট পাঠ

আমিজে চোগোত্ ভাজে ত' আঝি ;

ঘুম্ নেই দ্বি চোগোত্ ;

এগোর ওগোর গদা রেত্ ;

পুরিযায় পহঁত্যা রাঝিঁ।।।

আগাজত্ নেই তারা পহর ;

মন' কধা কোম্ ভিলি এক্এয়র।

কধা কধুং তারা'লোই ;

ইরুক্ কধা কঙ্ যারালোই।

কালা মেঘে ঢাগি যিয়ে দেবাবো ;

রিপরিপ্ অশীজি র'!

ডগরের কবা'বো!!!

মনত্ জবং ;

সপ্পানত্ নাঙ্ ঘিনঙ্ ;

সময় অসময় ন' চিনঙ্ ;

কধা বাট্টাত্ মর নেই ভেল্।

পানি খাদে যুনি বিষুম্ যাচ্ ;

পারংভিলি পারং ভাচ্ ;

হুরি হুরি ন' দিচ্ গেল্।।।

চুল্ বেরেই ছত্রং ফুল্ রাগেদে গুজে ;

নুদি আঝি,

নুদি চোখ্ ;

ঈধোত্ উদিলে এ বুগোত্ ;

এ পরান্ যোক্ থোক্!!!

এ মনান্ পাগল্ সান্,

কানে আঝে ;

পরানবী যুনি তর মিধে আঝি ;

মর দ্বি চোগোত্ ভাজে।।।

কবিতা সংগ্রহে ফিরে যান
