হোচপানার চারাগাছ

তারিখ অজানা — 1 মিনিট পাঠ

কাক্যাবাচ্যা মর নীরোচ্ মনত্ ;

পাগত্ পুরি তুই কন্ হেনত্।

তুলি পারচনি ঈদোত্ তর মনত্।

জেক্ জেক্ নাহি বিগিদি গুরি ;

হোচপানার বীজি চারে গেলে ।

সিবে বহুত্ আগে মাদি ফুরি,

ছাবা দের মর মনত্ নিলোজ্ গুরি।

যে মনত্ দাদি হের ন' বাজে ;

বিন্যা রাঙাঁ বেল্ ন' আঝে।

যে মনত্ জরান্দি হধা ন' রজে।

সে জাগাত্ তর হোচপানার বীজি,

ভেরভেরেই কেনে উধে তিদি।

ধেলা-পাগোর অ'সায়র,

নিত্য ফুল্ কেনে থান্ ফুদি।

সে গাজর ছাবাত্ তলে,

দিন্নো এলে........

কদ' পেগে নাগর্ মাধি যান্ ;

লাঙ্যাঁ-লাঙোঁনীর ন' ফুরেয়ে গান্।

যে গানর সুরোত্ ফুল্ ছড়া,

ফুধি থান্ করাহ্ করাহ্।

উড়ি যায় তুমবাচ্ চেরোপালা।

মুই নেই ম' মনত্ ;

তুই নেই ম' ধাগত্।

পুরি আগঙ্ আকুলত্ ;

অঘুর নিবিলির তারুমত্!

নেই নেই তর দেঘা নেই ;

নাহি আগচ্ কন্ মনত্ আবর হেই।

পথ্য মানুচ্ ধুরি ধুরি ;

সুখ্-দুগোর্ হধা নিয়ালজি গুরি।

কোই চেলুঙ্ ভাঙীঁচুরি।

এক্কা এক্কা তর মুয়ো আরুক্ ;

আঙিঁভুঙিঁ ঈদোত্ তুলি।

যা চেলুঙ্ কবার ;

কারর ধারাচ্ নেই শুনিবার।

উতসরেবে কমলে তর লাগেইয়া চারা?

বাচ্চে আগঙ্ মুই, কন্ তর কবাল্ পরা!!!

করাহ্ করাহ্ = গাজিক্ গাজিক্।
