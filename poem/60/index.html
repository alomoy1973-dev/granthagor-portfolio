ঈধোত্ উধে

০৬/০৭/২০১৫ — 4 মিনিট পাঠ

দোগিন্ দোরি মোন্ ঘরান্ ;

এলায় বাজে বুইয়ারান।

কুদু আগচ্ মর পরান্ ;

ঈধোত্ উধের দিন্ মাধান্।

নাগে কুচকুচ্ ত' ভুজি ;

রিনি চায়দি চোখ্ পিজি।

তাত্তুন্ তরে বো নিবার ;

পুরোন্ ছিনে বান্ দিবার।

কদক্ আওচ্ মনানত্।

উড়ি পোলুঙগি সে হেনত্।

আওজো আঝা মাদি ওল্ ;

সেনে মরে বেজার ওল্।

ত' মা-বাবে কোচ্ পেদাক্ ;

কিচ্ছু ফেলে ন' খেদাক্।

কদক্ সুগোর জীংকানি ;

অক্ত বেঅক্ত তোন্ রানি।

রুজোক্ ন' রুজোক্ ভাত্ পানি।

কদ' কধায় সাজ্ গুঙিঁ।

হরা হরা বিগুনো কুজি ;

সিদোল্ দলা দিধে ফুঁজি।

উধোত্ মূয়োত্ আগে বাজী ;

কুদু গেলাক্ দিনুন্ আঝি।।।

ভাদ' মাস্যা ক'জুর সান্ ;

কাদেবার কধা জীংকানিয়ান্।

কন্ বৈজাগর বড় ব' ঝড়ত্ ;

গাজ্ ভাঙীঁলাক্ সংসারত্।

কালা পিগিরা,

কালা দেন্ ;

দেজত্ সমেলাক্কি অজিরেন্।

গোদা দেশ্চানত্ হিলহিলেই ;

ভুজুংভাজুং ভিলভিলেই।

দোদোক্যা গুন ছ' চোগোত্ পুরি ;

অলিব্ ন' গুরি তরাতাঙুরি।

তুলি নিলেক্ আত্ত্যার' মুয়োত্ ;

দশশিরে রাবনা সানগুরি।।।

গুন্ ছ' = জুমো চিন্দ্রা ফল্।

কবিতা সংগ্রহে ফিরে যান
