ভুদেপা দেখ্যের বাপ

তারিখ অজানা — 1 মিনিট পাঠ

"ভুদেপা দেখ্যে" মোন্ উদে ;

ধুন্দোমিধে চুমো আ ঢিবেদ্যে।

পুল্যাঙ' কাজাত্ মিধে চুমো ;

বুইয়ারে ডগরের উঁঞোঁ...উঁঞোঁ...।

ভুদেপা ভাবের ভুত্তো এল' ;

তে আর' বেশ্ গঙদি গেল'।

যেদক্ গঙেঁ যায় ভুদেপা ;

সেদক্ ভুদো এজের পাহ্!

শেঝ্ মেঝ্ দিল' ধাবা ;

চুমোবোত্ বাজিল' জুড়ে আহবা।

ঘরত্ লুঙিঁ কয়ধি তা মোক্কোরে ;

ভুত্তো দেবো আঞ্যেঁদে লোড়ে!

বাড়ে দিলগিদি ঘর সঙ্ ;

ঘরত্ উদি চেদগি এক্কা হি গরঙ্!

হুচ্ দি চেদগি ম' ঘরত্ ;

পরান্ কারি লোদুঙ্ চাবরত্!!!
