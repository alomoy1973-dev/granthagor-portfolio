হিল্ চাদিগাঙ্

১২/০৬/২০১৫ — 4 মিনিট পাঠ

এগাচিত্তে মন্ খুলি ;

দুলূ বাজর দুলূক্ তুলি।

এগাধ্যান্,

জোপ্ নেই ;

চিমচিম্যাঁ খাপ্ বানেই।

চুচ্যাং মাধালোই এক্কান্ নাঙ্ ;

চিদোত্ তুলিলুঙ্ আঙ্।

যেন্ ভুলি ন যাং ;

হিল্ চাদিগাঙ্,

হিল্ চাদিগাঙ্।।।

এ বুগোত্ আগেলুঙ্ ;

ন' বুল্যা আধে পাগেলুঙ্।

ভিন্দে,

জাত্ত্বে এফুর ওফুর ;

গুরিলুঙ্ বুক্!!

ভাবনার রানজুনি রঙেঁ ;

সাজেবার সাজেলুঙ্ গঙেঁ গঙেঁ।

অলে ওক্,

ন'লে নেই ;

নেই মর দুখ্।

এক্ ছবি এক্ নাঙ্ ;

হিল্ চাদিগাঙ্,

হিল্ চাদিগাঙ্।।।

কি রগ্,

কি লো শিরা ;

গদা কিয়ের গিরায় গিরা।

যেন্ সপ্পানত্ আধের নাল্।

সত্তা,

শংখ,

মাতামুহুরি ;

চিগোন্ চাগোন্ ছড়া জুড়ি।

লেলাং,

ধুরুং খাল্।

গঙাঁরত্ উদোহারি,

জগার পারি ;

জবে এক্কান্ নাঙ্ ;

হিল্ চাদিগাঙ্,

হিল্ চাদিগাঙ্।।।

দুলূক্ - বাজর চিলোদির ধারপাত্তি।

২*চিমচিম্যাঁ - যদেবদে ধার।

৩*খাপ্ - বাজর ছুরি।

দ্বি ধাগেদি ধারপাত্তি,

মাধান্ চুচ্যাং।

৪*আঙ - অংকন চিত্র (বাংলায়) নিদিষ্ট হিজু আগানা।

তাবিজ' লেঘা।

৫*উদোহারি - পানি গঙাঁরত্ ঘুল্ উদোরে উদোনা।

৩*খাপ্ -

কবিতা সংগ্রহে ফিরে যান
