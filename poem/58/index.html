কোবিদ্যার (লামার) বাঈনি(কবিতার মাহাত্ম্য

০৪/০৭/২০১৫ — 6 মিনিট পাঠ

কাবিল্ কাবিদাঙর একবুক্ স্ববনর ;

কিজু র',

কিজু অহরক্ ভাচজরা দেনা।

সে অহরকলোই মন' কধার,

দেবংশি ভাবনানি.... ।।

ফুল্ছড়াত্ য়ালী গাধে ;

কিজু উম্ উম্ বঃনিঝাস্ মিজাল্ দেনা।

সিবেরে কোই লামা।।।

তর হিরিমিরি হেলালীলা সয়সাগর।

চোখ্ নেই দেগচ্।

কান্ নেই শুনচ্।

আধ্ নেই পিত্থীমিয়েন্ ত' মুধোত্।

পেঠ্ নেই পিত্থীমিয়েন্ ত' পেদত্।

ঠেঙ' নেই আধি পারচ্।

তুই কানেই পারচ্।

তুই আঝেই পারচ্।

তুই মারিয়্য পারচ্।

তুই বাজেয়্য পারচ্।

চিয়োম্যা মনত্ সাহস্ বানিদোজ্,

বানিদোজ্ বুক্ য়াজার রাঙাঁ স্ববনে।

বুগোপাদা ভাঙীঁদোজ্ গাবুরোমনত্,

বলবলা স্ববনানি ফেরেদোজ্ বঃনিঝাজে!!!

ঘর' মানুচ্ পর গুরি দোচ্ ;

*ছুরকাবোজ্ দোচ্ আধত্ তুলি।

বেক্কুনরে একজধায় আনিও পারচ্ ;

এক্ সুধোনালে গাধে তুলি।

যুনি অচ্ ইক্কুয়া দোল্ কোবিদ্যা (লামা)।।।

০৪/০৭/২০১৫

১৩১)ছড়া( বাংলার কবি জীবনানন্দ দাশত্তুন খেমা চে......)

মরে পেবা

মরে তোগেলে পেবা ;

সেঙেঁ কাজলঙঁর বাগে বাগে।

হুদু নাদেং কুত্তি,

হুদু পেরা ;

নয় পাঁদি ঝাগর ঝাগে ঝাগে।

ঝাগ্ ঝাগ্ তদেক্ উড়ি যান্ ;

সাজ্ গুঙিঁ যাদে দেভা।

যুনি মরে পেবার চেলে ;

সেই তদেক্ ঝাগত্ও পেবা।

মুই থেম্ হেঁশ্যাফুল্ ওই ;

এ দেজর গাঙ্ কুলে কুলে।

মুই থেম্ বিঝু ওইনে ;

নানা রঙর ফুলে ফুলে।

কাট্টোল্ ফাপোক্ ওইনে থেম্ ;

এ দেজর তারুম্ ঝাড়ত্।

জুমোত্ হুজি ধান্ গাজ্ ওইনে থেম্ ;

বৈজাখ্ জেত্ মাজত্।

আগাজর শারাল্যা ওই খেম্ ;

ফাগুনোত্ চিক্ চিক্ র' ছারি।

বিঝু পেক্ ওইনে থেম্ ;

ঘর' হুরে শমিগিলত্ পড়ি।

মুই থেম্ গাজ' ছাবাত্ ;

গরু চরাঞ্যাঁ ওই।

মরে দেভা শিঙেঁ বাধে ;

গারেঙ্ ঘরত্ বোই।

মুই থেম্ গাজ' ছাবায় ছাবায় ;

এ দেজর পধে,

ঘাধে।

ধল্যাপুক্ ওইনে ইধু থেম্ ;

অন্যঁ দেশ্চানি বাদে।।।
