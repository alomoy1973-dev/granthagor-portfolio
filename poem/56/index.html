স্ববনে দেগঙ্

০১/০৭/২০১৫ — 4 মিনিট পাঠ

আঝানেই যে স্ববন্ পত্থমে দেগিবার ;

সে আঝা স্ববনে দেগিম্ ভিলি....আঃ গোজেন্!!!!!

ধুপ্ খবং তদাত্ বেরেই এগামনে,

ডাগ'ঙর দ্বি আধ্ জুর গুরি।

মর কাজা ঘুম্ ন' দিস্ ভাঙীঁ।

ঘুমে ঘুমে,

দোল্ দোল্ স্ববনে,

আঝিযোক্,

ভাজিযোক্ মনানে।

অজিরেন্ যাং ঘুম্......যে স্ববন্ সুঘোর নেই কোনো থুম।।

পত্থমে দেগঙ্ বানাহ্ আবিলেস্!

মিজিযের বেজাদে,

নেই কোনো রেশ্।

কধা নেই ধরাধুরি ;

গুরির দ' গুরির লড়ালুড়ি।

আরে যের জাগা মাদি ;

ত' কায়,

ম' কায়।

যোগ-বিয়োগ,

গুণ-ভাগ ;

অবশেঝ্ আধত্ থায়,

গায় গায় গায়!!

এঞ্জান্ অলে জিদেজিত্যা যুগোত্,

কেনে তিগানা সংসারমায়!!!

মুই স্ববনে দেগঙ্....এ দেজর মুড়োমুড়িত ;

গাঙ' পাড়,

ছড়াছুড়িত্।

ছত্রং ফুলর তুমবাচ্ রঙেঁ ;

আঝি হুজি জনে জনে।

ঘর বানি কাদে দির ;

এ দেজর জাগা মাদিত্।।।

গুরো ভেই বোন্ আধে ধুরি ;

ছড়াছড়ি,

মুড়োমুড়ি।

পার ওই আধি যেই ;

ভুইয়ো পথ্ নাঙেঁল্ বেই।

শিঘদন্ জাদর ভাচ্ নিজ' ধগে।

জাদর ভাজে গীত্ গেই ;

আদাম্ দীঘোলি বেড়াদন্,

"মা ভাজে" র' ছারি.........ন' চাং যেবার এ জাগান্ ছাড়ি,

ইধু আগঙ্ জনমান্ ধুরি........ ।।।

কবিতা সংগ্রহে ফিরে যান
