মন

০৫/০৭/২০১৫ — 4 মিনিট পাঠ

যেক্কেত্তুন্ ধুরি ঈধোত্ গুরি ;

মন্,

তল্লোই আগঙ্ সংসমারি।

ন' পাঙর তরে ধুরি ;

কায় গেলে যাচ্ উড়ি।

বানিলে বান্ ন' মানজ্ ;

ইরি দিলে *কুত্ ন' ছারজ্।

ধুরি পাং ন' পাং মনান্ মর ;

পুষ্ কিয়া ন' মানজ্।।।

আধ্ বাভে যারে পেভে ;

আদে-কাঝে যারে দেভে।

সুগে-দুগে নিত্য সমার ;

সমাজ্যা ভাবী আধও বাভার।

তারে দ্যুর দুরোত্ ঠিলি ;

পাত্তা ন' দ্যুর চিগোন্ ভিলি।

ন' বুজঙ্ মনান্ মর ;

কাদেলুঙ্ এদক্ বজর।

ভিখারি ঘরত্ রাজা কিয়া সাজর???

ও মন্,

পুষ্ কিয়া ন' মানর।

এদক্ তরে বুজে চেলুঙ্,

আ কিয়া ন' বুজর।।।

আগাজর চান্-তারা ;

আধ্ বাভেলে পেব' পারা।

যারে পেদে নয় আধে ধুরি ;

তাল্লে মরর হায় হায় গুরি!

কধে চাং মনান্ মর......কাদেলুঙ্ এদক্ বজর।

যে তর নাঙ্ লধও লাজায় ;

তুই মরর তা আঝায় আঝায়।

বুজেলে ন' মানজ্ বুজ্।

দিন্ দ' ফুরেই গেল' ;

কমলে বুজিবো ঊজ্!

তরে তুই কিয়া বুজে ন' পারজ্???

এদক্ চেলুঙ্,

পুষ্ কিয়া ন' মানজ্।

"মন্" পুষ্ কিয়া ন' মানজ্।।।

কুত্ = নিজ জাগা,

গিরোজ,

নিজর গিরোজ।
