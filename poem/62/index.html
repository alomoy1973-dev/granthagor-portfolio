ছুলোনি-পরানি

১৪/০৭/২০১৫ — 2 মিনিট পাঠ

কুদু গেলাক্ গেংখুলি ;

গীত্ গেদাক্ মন্ খুলি।

ঊভোগীত্ হেংগ্রং ;

আঝি হুঝি রঙ-ধঙ্।

ধুধুগর তালে পেক্ ধাবানা ;

বাজী র' তালে ঊভোগীত্ গানাহ্।

নেইয়ার ধনপুদি ;

নেইয়ার রাধামন্।

কোরবুদি আগে বুংয়োছেরে,

বানাহ্ দুখ্ বনাহ্ বনাহ্!!!

সেক্কে দিনোত্ কোচপানা ;

ইক্কে দিনোত্ ঊজুরি যানা।

দোল্ নেই মনানি।

যেদক্ চলির পরর ধগে ;

হাচ্চেক্ বদলের রগে রগে।

বাড়ী যার ছুলোনি-পরানি!!!

কবিতা সংগ্রহে ফিরে যান
