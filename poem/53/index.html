ভাবনার রাধামন্-ধনপুদি

২২/০৬/২০১৫ — 5 মিনিট পাঠ

মুই হঙর ভিলি কাররে ন' হোচ্ ;

সিধেনর *ঝাপ্পান্ থক্ দি থোচ্।

পিবির পিবির বুইয়ারানি ;

লগে ছত্রং ফুলর তুমবাচ্চানি।

যুনি থায় তর আওচ্ ;

ত' কিয়েত্ গুলি লোচ্।

নানান্ ফুলর তুমবাচঅ রুক্ ধুরি ;

জুরো জুরো বুইয়ারর পিদিত্ চড়ি।

সে বুইয়ারর আগায় আগায় ;

ভাবী লোচ্,

মুই গায় গায়।

জুচ্ জুচ্ গুরি ত' কায় ;

এম্ চ্যা মুই হামাক্কায়।।।

ছত্রং ফুলর তুমবাচ্ পেলে ;

ভাবীলোচ্ মনে মনে তুই...পুড়ি আগচ্ ম' করত্ ;

খারা হঙর ত' চুলানিলোই মুই।

চোগে চোখ্ এক্ রিনি...কন' জোপ্ নেই মূয়েনদি।।।

শিরো পানিয়ে ভিজি গেলে যোক্ ;

রেত্ নীঝি অবারলাক্ ওক্।

বাচ্চে থেবে ঝাপ্ তুলি ;

আল্যাঙ্ মনর দোর খুলি।

যুনি ভাবচ্ মরে রাধামন্ ;

তরে ভাবচ্ যুনি তুই ধনপুদি।।।

ঝাপ্ - বুইয়ার আ পহর ছমবার ডাঙর কানার ঢাগুনি।

নাদি পারে খুলি পারে।
