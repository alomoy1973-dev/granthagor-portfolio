মিয়াঁজাল্

২৬/০৬/২০১৫ — 4 মিনিট পাঠ

যুনিও এদক্ ন' ভাবঙ্ ;

কন্ হেনত্ পুরি আগঙ্।

ঊড়উড়েই লড়ে লড়ে ;

চহদে বো মুরে মুরে।

ইক্কে এবল্ হায়হুরে।

ঝিমিদত্ গেলাক্ বিদি ;

গাবুরর দিন্ কাল্।

রদ্-বল্ ফুরে গেল্ ;

বে সুঞ্জুক্ বুড়ো কাল্।

কয়দিন্ থানা পেদেপেদে ;

দেঘা যার ভেদভেদে।

ঘিরাত্ পুজ্জঙ্ কনাছেরে,

মরনান্ ইক্কে হায়হুরে।

আগে কদক্ দোল্ এলুঙ্ ;

বার গরে পা মূয়োচেরাক্!

*ফেনটেন্ গুরি দেঘিয়োঙ্ ভেরাক্ ভেরাক্।

পাত্তা ন' দোং যারে তারে ;

দেমাগে অহদত্ হুচ্ ন' পড়ে।

গঙবলা গাবুর' জীংকানি ;

গুঙিয়োঙ্ দিম্মাদান্,

ন' এল' ভাবনা।

এলায় এলায় গুঙিয়োঙ্ দিন্ ;

দাম্ ন' দোং কারর চোগোপানি।

আদে হাজে বুড়োবুড়ি অ'সায়র ;

এক্ দিন্ বুড়ো ওম্ মুই,

ন' ভাবঙ্ একতিল্যা ছর।

দিন্ শেজত্ সাজুঞ্যাঁ মাধান্ ;

তবাহ্ বুদি এজে পরানান্।

বিদিযিয়া দিনুনোর যোগ-বিয়োগ ;

ভাবীলে জুরোয় পরান্ পিয়োক্ পিয়োক্।

মিয়াঁজাল্ পিত্থীমি ;

যা পুরিব' সাতনাল্ সুধো ছিনি।

য়াজার্ ধুরি থাক্ আধে আধ্ ;

নেই কোনো হেমাহেমী!!!

ফেনটেন্ - মেকআপ্।
