০৩/০৭/২০১৫ — 6 মিনিট পাঠ

কুজি মুক্যা চঙঁর' ধক্ ;

কানজাবা চুল্ গুলোদক্।

দগিনোর মাত্তল্ বুইয়ারে ;

দোদোক্যা গালচাবাত্ আবরে।

মনে কয় থাক্ রিনি চে!!!

চোঘোলেজর পেজত্ পুরি ;

কয়দিন্ থেম্ ঘুরি ঘুরি।

কাদাঙর দিম্মাদান্ ঝুরিঝুরি ;

যুনি তুলি লচ্ আধে ধুরি।

মর আওজর চিগোন্ বে!!!

বুগোত্ বাজী চিকছড়া ;

আঝি হুজি ধহল্হরা।

চুলোত্ গুজে নাকশাফুল্ ;

দি এক্কান্ উড়ের ঠিগিনী চুল্।

উধিল' বেবের রংফুধি!!!

আগাজর পুন্নিমা চান্ ;

ঝুরি পল্ল' পারাপাং।

মাদি পিত্থীমি পহর ওল্ ;

সেদক্ পরানবীরে লাগের দোল্।

চান্দবী!

না ধনপুদি!!!

ভজামুক্যা সান্ দাধ' রং ;

বেঙা-হোঙা চোঘোবং।

যুনি দেগঙ্ মুয়োত্ আঝি ;

মন্ রিবেঙ্ উধে নাজি।

জুম্ চাগালার জুম্মবী!!!

সনাততালি পেগোসান্ ;

কধানিও তার অয়য়োই গান্।

আরন্দি রাজার দেজত্ কেনে বাজিবো ;

তং-কুলো বেজিয়া বুজ্যা ঝিবো।

দুঃখ্যা চিগোন্ বে ক'বি!!!

ক'বি = চাংমা পশ্চন্ ক'বি ধ'বি,

সে ক'বিরে নিনে লেঘা।

"পিজে ফেলে"

পুনোত্ ঘু মাধাত্ পানি ;

অভাব্ নিধুকতুক্ জীংকানি।

*চাদারা ফুরি যে,

আর' চাদারা ফুরঙর।

মনে মনে ভাবঙর ;

কি কাম্ গরঙর।

বেক্ কিজু বুজিশুনি ;

রঙ্যাঁ ভুদে মরে কন' গাঝা গল্লনী!!!

উন্দুরবো উদের আর পরের ;

গোজেনে কানের না আঝের।

এ মাধানত্ ফেসবুক লারানা,

মরে সবাই ন' সাজের!!!

মর সংসমাজ্যায় ;

সংসার রিনি চেই।

আয়,

ইনকাম্ ঠিক্ রাগেই।

যা ধগে তে,

দুখ্কাম,

বেগার,

চাগুরি।

মুই খাঙর,

গরাজ্ গরাজ্ মেগাবাইট।

খরচ্ গরঙর দিন্-রেইত্ ।

কন্ ফুগুদিকানাদি পহর দেঘি ;

আগঙ্ বানাহ্ সংসার চুগি।।।

ম' ভাজে লিঘিলুঙ্ সাজে সাজে ;

মরে বাজে,

তারে বাজে।

কিয়রে ন' পারিলুঙ্ কানে ;

ন' পারিলুঙ্ আঝে।

রিপরিপ্ দুরোত্ গেলাক্,

সংসমাজ্যায় মরে ফেলে।

মুই আগঙ্ ঘোনাঘুনি কনাছেরে ;

ইয়ানি হি মর লকফক্।

পাল আরেইয়া বান্দর' ধক্ ;

ছেরেদি পুরি রলুঙ্ পিজে।।।

চাদারা = এক ধুক্যা পাত্তর।
